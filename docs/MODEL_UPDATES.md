# B01：模型时效与更新

行情更新、研究快照和参数有效期是三个独立状态。网页按当前 UTC 日期显示 V3 模型是否过期；所选日期仍决定可查看的历史记录或冻结结果。参数过期后不会用于有效期外的当前预测，也不会隐藏已有历史证据。

当前冻结参数适用于 `[2026-09-01, 2026-10-01)`；研究快照截至 2026-09-16。打开旧快照、切换历史日期、刷新行情或导入 CSV 都不会延长这个有效期。导出的分析 JSON 包含 `researchModelStatus`，记录导出时的状态、检查日期、有效期和研究快照。

## 更新路径

1. 按既有研究协议取得并校验连续、已完成的 UTC 日线；保留数据来源与哈希。
2. 仅使用在重训日之前已经成熟的标签，不修改固定候选或按历史成绩追选参数。
3. 在隔离的 Python 环境运行 `btc-trend-research/v3/audit.py --checks-only` 和完整审计，检查时间隔离记录与实验报告。
4. 用 `python3 btc-web/build_data.py` 生成网页研究数据，运行 `node --test btc-web/*.test.cjs` 和 JavaScript 语法检查。
5. 在独立分支审阅数据、参数有效期、报告与网页差异后发布。审计失败时继续显示模型过期，不能直接修改到期日期。

B01 只改时效展示和校验，不重新训练模型或改写冻结研究。下一轮 B02 再实现可复现的更新流水线。现有 V3 未建立额外预测优势；参数仍在有效期内也不表示其效果已经获得前瞻验证。
